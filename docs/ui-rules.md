# UI Rules

## Design Style

* futuristic minimal
* distraction-free
* emotionally calming
* dark mode only

---

## Inspirations

* Linear
* Notion
* Duolingo streak psychology

---

## UI Principles

* clean typography
* subtle animations
* minimal clutter
* focus-oriented layouts
* soft shadows
* rounded cards
* modern spacing

---

## Colors

Background:

* black
* deep gray
* dark blue

Accent:

* neon blue
* purple
* cyan

Avoid:

* too many bright colors
* childish gamification
* excessive gradients

---

## Components

Use:

* cards
* progress bars
* streak indicators
* heatmaps
* sidebar navigation
* clean forms

---

## UX Goals

Users should feel:

* focused
* motivated
* calm
* consistent

The interface should feel like:

> “a quiet mission control center for personal growth.”
